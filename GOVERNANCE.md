# Governance

- **Maintainers** review and merge pull requests, cut releases and own the roadmap.
  Current maintainers: the 1instinct team (list to be added).
- **Decisions**: small changes by pull-request review; architecture by ADR; extension API
  and public contracts by RFC in GitHub Discussions with a 7-day comment window.
- **Becoming a maintainer**: sustained, high-quality contributions and reviews; nominated by
  an existing maintainer and agreed by the others.
- **Forks** are encouraged. Keep brand changes in `distributions/<name>/` (see
  `docs/forking.md`) so you can keep taking upstream updates.
